# Droits des fichiers et répertoires

Possèdent des droits sur 3 niveaux :

* **utilisateur**
* **groupe** (pas forcément celui du propriétaire)
* **autres**

3 types de droits :

* **r** : lecture
* **w** : écriture
* **x** : execution

Représentés sous forme de la chaîne de caractères :
```bash
rwx rwx rwx
```

Si un droit n'est pas attribué à un niveau, on remplace la lettre par un `-`.

```bash
rwx rw- r--
```
Le droit d'exec est nécessaire pour lister le contenu d'un fichier.

## Représentation binaire

1 pour un droit attribué
0 pour un droit refusé

```bash
111 110 100
```

## Représentation décimale

On convertir chaque groupe de 3 bits

```bash
764
```

# Prefix des droits

* `-` fichier orfinaire
* `d` répertoire
* `l` lien symbolique
* autre : fichiers spéciaux
