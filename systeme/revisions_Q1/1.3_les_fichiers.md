# Les fichiers

## Types

* fichiers "classiques" (documents, images...)
* répertoires (dossier)
* fichiers spéciaux (périphériques par ex)

## Inode

Les fichiers sont identifiés par un inode.

L'inode contient :

* Le numéro d’inode
* La taille du fichier
* L’identifiant du périphérique contenant le fichier
* L’identifiant du propriétaire du fichier, ainsi que celui du groupe
* Le mode du fichier (ses droits d’accès)
* L’horodatage du fichier (date de modification de l’inode, du fichier et de dernier accès)

L'inode ne contient pas le nom (car le fichier peut être présent à plusieurs endroits).

On peut afficher l'inode d'un fichier avec :

```bash
ls -i fichier.txt
```

## Arborescence

Sous Linux, il n’y a pas de lettres de lecteurs comme `C:` ou `D:` sous Windows. Tout est organisé dans une seule arborescence qui part de la racine `/`

Monter une partition (comme un lecteur externe par exemple), c’est la rendre accessible en l’associant à un répertoire de l’arborescence unique de Linux.

Répaertoire utilisateur : `/home/<idUser>/`
